Cmd+Meow

A menu bar app for the Mac chores I kept installing separate apps for. Clear caches, find what fills the disk, uninstall properly, grab the screen, keep the clipboard, stop the Mac from sleeping.

Download macOS 12+ · Apple silicon & Intel · MIT

What's in the menu

Ten tools. Switch off the ones you don't use in Settings and they stop running.

Monitor
Mac HealthCPU, memory, disk, network, battery and Bluetooth device batteries
FansFan speeds and temperatures, manual control
Claude UsageHow much of your Claude Code limit is left
Clean
Clean UpCaches, logs, build folders. You check the list, files go to the Trash
Disk MapEvery folder sized, biggest first. Runs when you click Map
UninstallerRemoves the app plus its caches, prefs and login items
Startup ItemsLogin items and launch agents in one list
Create
CaptureScreenshots with an editor. Screen recording with system audio and camera⇧⌘2
ClipboardHistory of text, links and images, searchable⌥⌘V
Utilities
Keep AwakeA switch. Or stay awake only while Claude Code is working

Sharing a recording

Record with ⇧⌘2, press Share. The file goes to an S3 bucket you set up (I use Hetzner), and you get a link like this:

cmdmeow.furman.cat/play/?v=https://…/a3f9…e1.mp4

It opens in a small player that works on phones too. Your keys stay in the Keychain. No account, no server of mine in between.

What it doesn't do

  • No telemetry, no account, no subscription.
  • No scans in the background. Disk Map and folder sizes start when you click.
  • Nothing is deleted outright. Clean Up and Uninstaller move things to the Trash.
  • Claude never reads your files. If you turn on the review, it sees paths only.

Install

  1. Download the latest build from Releases and move it to Applications.
  2. It isn't notarized yet, so the first time, right-click it and choose Open. Or run this once: 
    xattr -dr com.apple.quarantine /Applications/CmdMeow.app
  3. macOS asks for Screen Recording and Accessibility when a tool needs them. Full Disk Access helps Clean Up see more.

From source: cargo run --release. Needs Rust stable.
